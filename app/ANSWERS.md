# Практическое задание 9. Асинхронность и корутины

## Задание 1. Отмена установки приложения
Реализована эмуляция установки приложения с прогрессом 0..100%.
Для управления состоянием используется `StateFlow`, для запуска и отмены задачи — `Job` и `viewModelScope.launch`.
Кнопка меняет состояние: «Установить» → «Отменить (%)» → «Установлено».

## Задание 2. Загрузка рейтингов

**Результаты замеров (время выполнения для загрузки рейтингов всех приложений):**
- **Последовательно:** 61702 мс (61.7 секунды)
- **Параллельно:** 1518 мс (1.5 секунды)

**Вывод:**
Параллельная загрузка с использованием `async` и `awaitAll()` внутри `coroutineScope` работает **в 40 раз быстрее**, чем последовательная.
Это происходит потому, что при последовательном подходе каждый запрос ожидает завершения предыдущего, а при параллельном — все запросы выполняются одновременно.
